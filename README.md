# NeuroX

Премиальный digital marketplace для AI-инструментов и подписок.

Storefront, кабинет, админка, digital inventory. Выдача ключа только после серверного подтверждения оплаты.

## Запуск

```bash
cd neurox-app
npm install
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
npm run dev
```
